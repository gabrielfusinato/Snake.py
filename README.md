# terminal-snake-py

A classic Snake game built to run directly in the terminal using **Python**. 
This project was developed to practice **matrix manipulation** and logic involving multi-dimensional arrays.

🛠️ **Setup**

Install dependencies (used for keyboard input):
```bash
pip install readchar
```

🚀 **Execution**

To start the game, simply run:
```bash
python3 app.py
```

🧠 **Game Logic & Study Goals**

The core of this project is the management of an 8x8 grid. The logic covers:

* **Matrix Initialization:** Creating the game board using nested lists.
* **Coordinate Mapping:** Updating positions in the matrix based on row and column indexes.
* **Movement Logic:** Handling how the snake "slides" through the matrix by adding new head positions and removing the tail.
* **Collision Detection:** Checking boundaries and overlapping values within the array.

**Developed for study purposes: Python Fundamentals + Matrix Manipulation.**
